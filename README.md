# Personal Expense Tracker with Data Visualization

## Project Overview

The Personal Expense Tracker is a Python-based financial analytics project designed to help users track, analyze, and visualize their daily expenses.

This project allows users to:
- Record expenses
- Analyze spending habits
- Generate financial insights
- Visualize monthly spending trends
- Export reports

The project simulates real-world expense management systems using synthetic datasets and CSV files.

---

# Problem Statement

Managing expenses manually can be difficult and time-consuming. Many individuals struggle to:
- Track daily expenses
- Identify unnecessary spending
- Maintain monthly budgets
- Analyze financial habits

This project solves these challenges through automated expense analysis and data visualization.

---

# Features

- Synthetic expense dataset generation
- CSV file loading
- Data cleaning and preprocessing
- Category-wise expense analysis
- Monthly spending analysis
- Payment method analysis
- Highest spending category identification
- Average daily spending calculation
- Total spending analysis
- Data visualization using charts
- CSV report generation
